# 💳 卡神懶人記帳 PWA (信用卡回饋攻略 × 2 秒記帳)

專為台灣多卡族打造的**零個資風險、純前端 LocalStorage 信用卡攻略與懶人記帳 App**。
直接部署於 **GitHub Pages**，在手機 Safari / Chrome 點選「加入主畫面」即可像原生 App 一樣全螢幕使用。

## ✨ 核心功能

1. **📍 置頂「我現在在哪？刷哪張最好？」即時查詢器**
   - 點選 `🏪 便利商店`、`💄 康是美/藥妝`、`🍽️ 餐廳吃飯`、`🚇 搭捷運`、`✈️ 出國旅遊`，立即依回饋率由高到低排出手邊最優信用卡。
   - 直接顯示**推薦支付方式**（LINE Pay / Apple Pay / 實體卡）、**需切換權益名稱**（如：樂饗購、趣旅行、Pay著刷、玩旅刷）。
   - 點擊「⚡ 帶入記帳」一鍵把該地點、支付方式與最優信用卡帶入下方記帳區。
2. **⚡ 辦法 1 升級版：支付快捷鍵 + 單次彈性換卡**
   - 支援 `💚 LINE Pay`、`🍎 Apple Pay`、`💳 實體卡/刷卡`、`💵 現金` 四大快捷鍵，各自可設定預設綁定卡（例如 LINE Pay 預設永豐 DAWAY）。
   - **不一定每次 LINE Pay 都刷永豐？** 點選 LINE Pay 後，下方會直接列出你的卡片膠囊按鈕，點一下即可在 0.5 秒內把這次交易切換成 `台新 @GoGo` 或 `中信 LINE Pay`。
3. **🎟️ 智慧「每月領券 / 登錄」免打擾勾選機制**
   - 針對需每月領券（如台新 @GoGo LINE Pay 加碼券）或每月搶登錄（如富邦 J 卡日韓泰 6% 加碼）的卡片，提供**「⬜ 點我勾選本月已完成」**按鈕。
   - **勾選後當月就不再跳出干擾提醒**；跨月自動重置。
4. **📊 回饋上限進度條 & 防呆警告**
   - 自動統計每張卡當月累計刷卡金額，對照加碼上限（如星展 eco 海外 5% 每期上限刷 $15,000、永豐 DAWAY 加碼上限等）顯示進度條與超額警告。
   - 內建防呆提醒（例如：選到「國泰 CUBE + LINE Pay」時會自動跳出紅字警告 CUBE 綁 LINE Pay 無 3% 加碼；選到「便利商店 + 永豐 DAWAY」會提醒全家適用、7-11 請改刷台新 @GoGo）。
5. **🛡️ 100% 零個資上雲 (方案 A)**
   - 不記錄卡號、末四碼、有效期限或安全碼。
   - 所有卡片設定與記帳明細僅保存在你手機瀏覽器的 `LocalStorage`，GitHub 儲存庫中完全沒有私人帳務資料，並支援一鍵 JSON 匯出/匯入備份。

## 🚀 如何部署到你的 GitHub Pages？

1. 在你的 GitHub 建立一個新的 Repository（例如命名為 `card-tracker`）。
2. 將本資料夾內的 `index.html`、`manifest.json`、`sw.js`、`README.md` 上傳並 Push 到 `main` 分支。
3. 進入 GitHub Repo 的 **Settings ➔ Pages**，在 **Build and deployment** 將 Branch 選為 `main` 並按 Save。
4. 等待約 1 分鐘後，打開 `https://<你的GitHub帳號>.github.io/card-tracker/`，用手機瀏覽器開啟並點選「分享 ➔ 加入主畫面」即可！
